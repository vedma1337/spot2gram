# spot2gram

Показывает трек, который вы слушаете в Spotify, в музыкальном разделе вашего профиля Telegram. Работает со Spotify Free — Premium и ключи Spotify API не нужны.

[English](README.md) · **Русский**

> [!WARNING]
> Проект использует неофициальный интерфейс Spotify. Используйте его на свой страх и риск.

## Как это работает

Вы включаете музыку в Spotify на телефоне, компьютере или другом устройстве. Скрипт получает текущий трек, передаёт ссылку на него боту [@nowtrackbot](https://t.me/nowtrackbot) и отправляет полученное аудио в ваш Telegram-канал. Затем добавляет его в музыку профиля.

При смене трека музыка в профиле обновляется, при остановке (после небольшой задержки) или выходе из скрипта — убирается. Сообщения с аудио остаются в канале и используются повторно, если вы снова включите ту же песню. Если @nowtrackbot не нашёл трек («Audio not found»), скрипт удаляет это сообщение, убирает предыдущую песню из профиля и не спрашивает про этот трек ещё час.

Скрипт должен работать всё время, пока нужна синхронизация. Spotify на том же компьютере открывать необязательно: отслеживается активное устройство аккаунта. Spotify сам присылает скрипту каждое изменение, поэтому профиль обновляется за секунду-две.

## Что понадобится

- Python 3.10 или новее.
- Аккаунты Spotify и Telegram.
- Отдельный Telegram-канал, в котором ваш аккаунт может публиковать сообщения. Лучше использовать приватный.
- Cookie `sp_dc` из веб-плеера Spotify — ниже показано, где её взять.

## Установка

Скачайте проект и откройте терминал в его папке.

**Windows — PowerShell:**

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**Linux / macOS:**

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## Настройка

Создайте копию `.env-example` с именем `.env`. Если `.env` уже существует, просто отредактируйте его.

### 1. Получите cookie Spotify

1. Откройте [open.spotify.com](https://open.spotify.com) и войдите в свой аккаунт.
2. Откройте инструменты разработчика браузера: **F12** или **Ctrl+Shift+I**. На macOS — **⌘⌥I**.
3. В Chrome / Edge выберите **Application → Storage → Cookies**. В Firefox — **Storage → Cookies**.
4. Выберите домен Spotify и найдите строку **`sp_dc`**.
5. Скопируйте содержимое столбца **Value** в `SPOTIFY_SP_DC` в файле `.env`.

Cookie даёт доступ к вашей сессии Spotify. Не публикуйте `.env` и не передавайте его другим людям.

### 2. Укажите канал

В `CHANNEL_ID` впишите **числовой ID** канала для аудио, например `-1001234567890`. Нужен полный ID канала, а не его название, ссылка или `@username`.

Готовый `.env` выглядит так:

```ini
SPOTIFY_SP_DC=сюда_значение_cookie
CHANNEL_ID=-1001234567890
```

Необязательные настройки (время — в секундах):

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| `CLEAR_DELAY_SECONDS` | `15` | Через сколько после остановки убрать трек, чтобы короткие паузы не мигали. |
| `STALE_AFTER_SECONDS` | `600` | Убрать трек, если Spotify недоступен столько времени. `0` — не убирать. |
| `AUDIO_TIMEOUT_SECONDS` | `90` | Сколько ждать, пока @nowtrackbot пришлёт аудио. |
| `CLEAR_ON_EXIT` | `true` | Убирать трек из профиля при остановке скрипта. |
| `LOG_LEVEL` | `INFO` | `DEBUG` показывает каждый шаг. |

## Запуск

Из папки проекта выполните:

**Windows:**

```powershell
.venv\Scripts\python.exe main.py
```

**Linux / macOS:**

```bash
.venv/bin/python main.py
```

При первом запуске войдите в Telegram по подсказкам в терминале. Авторизация сохранится в `music_sync.session`; при следующих запусках вход повторять не нужно.

Теперь включите трек в Spotify. Через несколько секунд он появится в канале и в профиле.

## Если что-то не работает

Повторяющиеся ошибки пишутся в лог один раз, с напоминанием раз в 10 минут и строкой «OK again», когда всё восстановилось.

- `sp_dc cookie is expired or signed out` — получите новую `sp_dc`, замените её в `.env` и перезапустите скрипт. Срок cookie можно посмотреть в столбце **Expires / Max-Age** браузера; сессия может быть отозвана раньше.
- `unknown format` / `TOTP secret` — Spotify поменял свой неофициальный протокол. Скрипт пишет ошибку и повторяет попытку раз в 5 минут, но нужна правка кода.
- `Channel ... not found` — проверьте `CHANNEL_ID` и что ваш аккаунт состоит в канале и может в нём публиковать.
- `No audio for ...` — @nowtrackbot не смог достать этот трек. Скрипт попробует снова через час.
- `Spotify: network error` и похожие — скрипт повторяет попытки с растущей паузой. Сетевой сбой не считается паузой: трек остаётся в профиле не дольше `STALE_AFTER_SECONDS`.

Скрипт записывает добавленную им музыку в `state.json`, поэтому после перезапуска или падения он всё равно уберёт свой старый трек, а не оставит его в профиле.

## Файлы проекта

| Файл | Назначение |
| --- | --- |
| `main.py` | Точка входа: логи, вход в Telegram, запуск и остановка |
| `sync.py` | Решает, что показывать в профиле, и повторяет неудачные шаги |
| `spotify.py` | Авторизация Spotify и получение текущего трека |
| `telegram_music.py` | Запрос аудио у @nowtrackbot и обновление музыки профиля |
| `state.py` | Запоминает, что скрипт добавил в профиль (`state.json`) |
| `config.py` | Чтение `.env` |
| `.env-example` | Пример настроек |
| `requirements.txt` | Зависимости Python |
| `tests/` | Проверки синхронизации и обработки ошибок |

Тесты запускаются без отправки сообщений и изменения профиля:

```bash
python -m unittest discover -s tests -v
```

Используйте Python из созданного окружения `.venv`, как в командах запуска выше.
